# TrackBack Final Demo Checklist

Prepare one student, one security user, one admin user, and two pre-created reports (one lost and one found). Never show secrets or ownership proof in the recording.

1. Student registers or logs in.
2. Student reports a lost item and a found item with safe images.
3. Admin logs in, reviews the pending report, and approves it.
4. Use the matching endpoint/workflow to compare the approved lost and found reports.
5. Student opens an approved item and submits private ownership proof.
6. Security reviews the claim, verifies ownership, and approves it.
7. Security assigns a storage location.
8. Student schedules a valid pickup date and fixed slot.
9. Student opens the generated one-time QR code.
10. Security enters/scans the token, confirms college ID, and completes handover.
11. Student downloads the receipt and checks the notification panel.
12. Student submits a 1–5 feedback rating.
13. Admin opens Analytics and exports the safe CSV.

Before recording, confirm the API and matching `/health` endpoints respond, use a disposable demo dataset, and reset or archive it afterward.
